> 원천: `src/app/data/category-specs.ts`(기술 사양) · `src/app/data/catalog.ts`(카테고리) · `src/app/components/upload-page.tsx`(공통 항목·폼 특수 처리)

## 읽는 법
- **종류**: 선택(드롭다운) · 다중(여러 개 고르기) · yes/no(있음/없음) · 숫자 · 텍스트 · 빌더(행을 추가하는 묶음 입력) · 자동
- **보이는 조건**: `항상` 이 아니면 다른 칸 값에 따라 나타남 (예: `형식=패시브일 때만`, `카트리지 선택 후`). 하위 카테고리별 조건은 표마다 이미 반영됨
- **필수**: 기술 사양 칸은 전부 선택 입력 — 필수는 아래 "공통 항목"에만 있음
- **상태**: 전용 블록 있음(이 하위에만 나오는 칸이 있음) · 기본 블록(대분류 공통 칸) · 공통 꼬리만(타입 + 마감·전원·크기·무게) · 폴백(카테고리 스키마 없음 → 옛 자유 입력 칸)
- 칸 구성이 똑같은 하위 카테고리는 표 하나로 묶음
