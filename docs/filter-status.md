## 1. 작동 방식 한 페이지

매물 한 건이 DB에서 화면 카드까지 오는 길이에요. 위에서 아래로 차례대로 걸러져요.

| 단계 | 하는 일 | 파일과 줄 |
|---|---|---|
| ① 불러오기 `fetchListings` | Supabase `listings` 표에서 판매중(`status = active`) 매물을 최신 등록순으로 전부 가져와요. 페이지를 열 때 한 번만 | `listings.ts` 181~189, 부르는 곳 `browse-page.tsx` 93~100 |
| ② 바꾸기 `mapRow` | DB 한 줄을 화면용 매물(Listing)로 바꿔요. 영문 키(`used_excellent`, `power-amp`)를 한글로 바꾸고, 기술 사양(`specs.tech`)에서 필터가 읽을 값을 꺼내요(예: 정격 출력 글 "100W @ 8Ω" → 숫자 100) | `listings.ts` 74~178 (출력 파서 45~58, 범위 파서 66~72) |
| ③ 검색어 | 주소에 검색어(`?q=`)가 있으면 브랜드, 모델, 제목, 설명, 카테고리 이름으로 먼저 걸러요. 결과가 3건보다 적으면 한영 자판 오타(예: "akfksc" → "마란츠")도 찾아 더해요 | `browse-page.tsx` 160~229 |
| ④ 카테고리 | 큰 카테고리(앰프 등)에 속한 매물만 남기고(240~243), 왼쪽에서 하위 카테고리를 고르면 그것만 남겨요(246~249). 한 매물이 여러 카테고리에 걸릴 수 있어요(포노 스테이지 ↔ MM/MC 포노앰프) | `browse-page.tsx` 240~249, `browse-filters.ts` 194~202 |
| ⑤ 개수 세기 `counts` | 사이드바 선택지 옆 (숫자)를 ④까지 남은 매물로 세요 | `browse-page.tsx` 273~315 |
| ⑥ 필터 `applyFilters` | 고른 필터를 하나씩 적용해요. 카테고리 전용 필터는 그 카테고리일 때만 적용돼요 | `browse-filters.ts` 391~457, 부르는 곳 `browse-page.tsx` 382~389 |
| ⑦ 정렬 | 추천순(따로 정렬 안 함 = DB 순서, 즉 최신 등록순), 최신순, 가격 낮은순, 가격 높은순 | `browse-page.tsx` 384~388 |

### 범위 필터의 "빈 값" 규칙
- 숫자 범위(정격 출력, 감도, 권장 앰프 출력, 내 헤드폰 임피던스)는 공통 함수 `inRange`를 써요(`browse-filters.ts` 382~388).
  - 최소와 최대를 둘 다 비우면 모든 매물이 통과해요.
  - 하나라도 넣으면, 그 값을 입력하지 않은 매물(빈 값)은 빠져요. "0"을 진짜 0으로 오해하지 않으려고 빈 값을 따로 표시해요.
- 가격은 모든 매물에 있어서 문제없어요. 입력 단위는 "만원"이에요(입력 × 10,000으로 비교, 402~403줄).
- 출시년도와 정격 용량과 케이블 길이는 `inRange`를 안 쓰고 직접 비교해요(404~405, 440~441, 444~445줄). 빈 값이 0으로 들어가서:
  - 최소만 넣으면 빈 값 매물은 빠져요(0 < 최소).
  - 최대만 넣으면 빈 값 매물도 남아요(0 ≤ 최대). 다른 범위 필터와 규칙이 달라요.

### 여러 개 고르면
- **같은 필터 안에서는 "하나라도 맞으면"**이에요. 브랜드에서 Accuphase와 Luxman을 고르면 둘 중 하나인 매물이 다 나와요.
- **다른 필터끼리는 "전부 맞아야"**예요. 브랜드 Accuphase + 증폭 방식 진공관이면 둘 다 맞는 매물만 나와요.
- 매물 하나에 값이 여러 개인 필터(앰프 지원 임피던스, 스피커 드라이버 구성, 턴테이블 속도)는 매물 값 중 하나라도 고른 것과 맞으면 통과예요(416, 424, 435줄).
- 상태의 "중고"는 단축 선택지예요. 고르면 중고 등급 6개(민트급~작동 불가)를 다 고른 것과 같아요(394~401줄).

### 사이드바 개수 (counts)
- 세는 대상은 ③ 검색어와 ④ 카테고리까지 걸러진 매물이에요. 다른 필터를 골라도 숫자가 안 바뀌어요(예: 브랜드를 골라도 증폭 방식 옆 숫자는 그대로).
- 하위 카테고리 숫자만 하위 카테고리를 고르기 전 매물로 세요(268~271줄). 그래서 하나를 골라도 다른 하위 카테고리 숫자가 0이 되지 않아요.
- "중고" 숫자는 중고 등급 6개 숫자의 합이에요(276~283줄).
- 브랜드 목록은 매물이 있는 브랜드만, 매물 수가 많은 순서예요(318~321줄).
- 모바일 팝업은 같은 숫자를 받아 써요. 팝업 아래 "적용하기 (N건)"만 지금 고른 것으로 새로 셉니다(`filter-modal.tsx` 301~323).

## 2. 필터 상세표

읽는 법
- **입력**: 체크박스(여러 개 고르기), 범위(최소~최대 숫자 두 칸), 한 칸(숫자 하나), 드롭다운(펼쳐서 고르는 목록)
- **선택지 출처**: 선택지가 정의된 상수. `category-specs.ts`에서 오는 것은 판매 폼 선택지와 같은 목록이에요(필터와 폼이 같은 글자를 씀).
- **읽는 데이터**: 매물(Listing)의 어느 칸인지, 그 칸이 DB `specs.tech`의 어느 키에서 오는지
- **판정**: `=` 는 "매물 값이 고른 것 중 하나와 같음", `∩` 는 "매물 값 여러 개 중 하나라도 고른 것에 있음", 범위는 위 1장 규칙
- **사이드바 / 모바일**: 넓은 화면(lg 이상) 왼쪽 사이드바와 좁은 화면 필터 팝업의 차이. 사이드바는 고르는 즉시 반영, 팝업은 "적용하기"를 눌러야 반영

## 3. 작동 안 하는 필터

### 3-1. 판매 폼에 입력 칸이 없어서 아무것도 안 걸리는 것 — 10개
| 필터 | 이유 | 고르면 생기는 일 |
|---|---|---|
| 지역(공통) | 판매 폼에 지역 칸이 없고, 등록 때 DB `location`을 채우지 않아요(`listings.ts` `toListingRow` 237~267에 location 없음) | 어느 지역을 골라도 0건. 선택지 옆 숫자도 0 |
| 케이블 8개(길이, 입력 단자, 출력 단자, 도체, 도금, 차폐, 페어, 방향성) | 케이블은 폼 스키마가 없어서 옛 자유 입력 16칸(앰프용 칸)이 나와요. 값은 `specs.tech`에 자유 글로 저장되는데, 필터는 `specs.cableLength`처럼 tech 밖의 칸을 읽어요(`listings.ts` 168~176) | 체크박스를 고르면 0건. 길이는 "최소"를 넣으면 0건, "최대"만 넣으면 모든 매물이 남아요(빈 값이 0이라서) |
| 전원 장치 정격 용량 | 폼에 정격 용량 칸이 없어요. 또 큰 카테고리 "액세서리"가 카테고리 목록(`CATEGORY_TREE`)에 없어서 이 필터가 나오는 화면에 갈 길이 없어요(`docs/form-status.md` 531줄에도 적혀 있음) | 화면에 안 나옴(나와도 위 길이와 같음) |

### 3-2. 저장 칸이 달라서 일부만 걸리는 것 — 1개
| 필터 | 이유 | 고르면 생기는 일 |
|---|---|---|
| 포노 입력(앰프) | 필터는 tech `phono`를 읽는데, 포노 스테이지 3종(포노앰프, MC 스텝업 헤드앰프, MC 스텝업 트랜스)에는 폼에서 `phono` 칸이 숨고 포노앰프는 `cartridgeSupport`(MM, MC, MM/MC)에 저장해요(`category-specs.ts` 213, 267줄) | "MM"을 고르면 MM 입력이 있는 인티앰프와 프리앰프는 나오지만 MM 포노앰프는 빠져요 |

### 3-3. 숨겨져도 계속 적용되는 것
- 사이드바에서 필터 칸이 숨겨져도, 그 전에 골라 둔 값은 지워지지 않고 계속 적용돼요. 칩(활성 필터)으로 남아 있어 칩의 X로만 지울 수 있어요.
  - 앰프에서 정격 출력을 넣은 뒤 하위 카테고리를 프리앰프 하나로 바꾸면 정격 출력 칸은 사라지지만 걸러짐은 남아요. 프리앰프는 출력 값이 없어 0건이 될 수 있어요.
  - 같은 일: 지원 임피던스(프리앰프만, 헤드폰 앰프만일 때 숨김), 세부 카테고리(헤드폰 앰프만일 때 숨김), 차폐 방식(관련 케이블을 고르지 않았을 때 숨김).
- 반대로 카테고리 전용 필터(앰프, 스피커, 턴테이블, 케이블)는 다른 카테고리로 가면 칩도 숨고 적용도 안 돼요. 다만 값은 기억돼서 같은 카테고리로 돌아오면 다시 적용돼요(카테고리를 바꿔도 필터를 비우지 않음, 큰 카테고리 바뀔 때 하위 카테고리만 비움 `browse-page.tsx` 145~147).
- 모바일 팝업은 사이드바와 숨기는 조건이 달라요: 헤드폰 앰프여도 세부 카테고리가 보이고, 프리앰프만이어도 정격 출력과 지원 임피던스가 보여요.
